---
name: Nexus code review request
description: use when a completed change needs a bounded technical review before integration
---

Prepare a review scope from the requested change and the actual workspace evidence. Inspect changed files and their focused validation results. State the behavior being reviewed, the relevant files, the checks run, and any known limitations. Review evidence belongs to the exact change; do not substitute a broad repository scan for a focused review.

Use the existing Nexus review records and bounded workspace diff where they apply. The workflow does not create remote review requests, grant Git authority, bypass permissions, or treat a review request as approval to merge.

Ask for review only after the evidence is current. If a reviewer identifies a potential problem, use the review-reception workflow before changing code.
