# Codex reference skills

This folder contains a local reference copy of the Superpowers skill package
available in the Codex development environment at the time this folder was
created. It is reference material for designing provider-neutral Nexus skills;
it is not wired into Nexus runtime discovery and does not change which skills
are installed or enabled by the application.

The complete `skills/` tree is preserved, including each skill's supporting
prompts, scripts, examples, and references. Some entries are specific to a
particular agent harness or tool protocol and must be adapted before Nexus can
ship them to every model/provider.
