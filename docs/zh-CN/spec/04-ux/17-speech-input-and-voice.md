# 语音输入与语音对话

> **翻译说明：** 本页是与 [英文源规格](/spec/04-ux/17-speech-input-and-voice) 对应的机器辅助翻译。代码、协议字段和标识符保持原文；如有歧义，以英文版本为准。

- 输入框增加两个紧凑图标：麦克风用于语音输入，音频线条用于语音模式。两个按钮都有无障碍名称和悬停提示，不在工具栏常驻文字标签。
- 语音输入最长录制 60 秒。按「完成」后，转写结果作为可编辑纯文本插入当前草稿选区，不会自动发送。取消会丢弃录音。空结果或失败不改变草稿。
- 语音模式在输入框上方打开紧凑的浮动对话面板，不模糊、遮暗或阻断聊天和工作区。按「完成」后，当前语音回合通过现有消息发送路径提交，继续遵循会话的队列和权限规则。面板显示录音、转写、等待回复和朗读状态。用户可以停止朗读、再次说话或结束语音模式。朗读结束后重新开始聆听。
- 切换会话或卸载组件时，录音与朗读立即结束。迟到的转写结果不能插入另一段对话。
- 「设置 > 模型 > 语音」可选择本地或托管转写。本地为默认值，无需 API 密钥。托管模式可填写服务地址、模型和 API 密钥环境变量名。回复语音可以选择系统已安装的语音。
- 语音回复默认开启，以保留现有行为。关闭后仍可用语音输入，Nexus 以文字回复，并在回复完成后继续聆听；此时回复语音选择器不可用。
- 本地模型保存在应用数据中。音频只在录制和转写期间保留，不写入聊天历史或工作区文件。托管模式会将音频发送到用户配置的服务地址。
- 主进程仅接受大小受限的 16 kHz 单声道 PCM WAV。主窗口的麦克风权限只允许音频，与插件授权相互独立。托管服务必须使用 HTTPS；本机回环地址可以使用 HTTP。

参见 [ADR 0244](/adr/0244-local-first-speech-input)。
